# Kronecker Time-Varying Graphical Lasso (KTVGL)

This repository contains the implementation for the paper:

- [Interpretable Dynamic Network Modeling of Tensor Time Series via Kronecker Time-Varying Graphical Lasso (WWW 2026)](https://arxiv.org/abs/2602.08197)

## Branch Policy

- `main` branch:
  - Intended for paper experiment reproduction.
  - Keeps the original experiment-oriented code structure.
- `multi-samples` branch:
  - Intended for package/library-style usage.
  - Includes extensions for handling multiple samples at each timestamp.

If you want to **run the original paper reproduction experiments**, use `main`.
If you want to **use KTVGL as a reusable package from another project**, use `multi-samples`.

## Difference Between `main` and `multi-samples`

Compared with `main`, `multi-samples` extends the optimization/data pipeline so that KTVGL can be applied when each timestamp has multiple observations:

- `main`: assumes one sample per timestamp.
- `multi-samples`: supports one sample or multiple samples per timestamp (including variable sample count over time).

## Environment Setup

This project uses Poetry for dependency management.

```bash
poetry install
```

## Dataset

### Synthetic data

Synthetic datasets are generated by `generate_kron_data` in:

- `src/common/synthetic.py`

Experiment scripts such as `exp/train_ktvgl.py` use this generator.

### Real-world data

Real-world datasets used in the paper (Google Trends based datasets) are in:

- `data/`

## Reproduction (main)

Run experiment scripts in `exp/`, for example:

```bash
poetry run python exp/train_ktvgl.py --help
```
